# Examples

Usage examples demonstrating WAuth API capabilities.

## Available Examples

| Example | Description |
|---------|-------------|
| [`00 base/example.py`](00%20base/example.py) | Basic WAuth usage: initialize, store, retrieve secrets |

## Running Examples

```bash
# Run the base example
python "examples/00 base/example.py"
# Output: Retrieved token: 7483920:ABC-DEF-GHI
```

Each example is self-contained and cleans up after itself (removes temporary database files).
